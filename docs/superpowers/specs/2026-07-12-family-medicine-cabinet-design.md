# 家药箱（家庭智能药箱）— 产品设计规格

> 日期：2026-07-12  
> 状态：待用户确认后进入实现计划  
> 依据：原始 PRD、产品调研报告、本轮头脑风暴决策

---

## 1. 目标与定位

**一句话定位：** 全家共用的药箱清单——一人录入，全家能找；过期前提醒，生病时快速定位药品存放位置。

**差异化切入点：** 家庭多人共享（账号制、全员对等），而不是再做一个单机效期提醒工具。

**成功标准（验证阶段）：**
- Figma 可点击原型能走通主故事线，不卡流程
- 至少 5 名目标用户（有娃 / 有老人家庭）表示「会装」或「想拉家人一起用」
- 收集到的流程吐槽足以支撑改一版后再开发

---

## 2. 已确认决策

| 项 | 决策 |
|---|---|
| 主场景 | MVP：共用一个家庭药箱；后续：子女远程帮父母（极简找药） |
| 加入方式 | 账号制：创建家庭 / 6 位邀请码（或分享链接）加入 |
| 成员权限 | MVP 全员对等（均可录入、修改、删除、查找）；管理员/仅查看后续再加 |
| 市场 | 先国内（中文，中国区 App Store） |
| 平台 | 仅 iOS |
| 原型形式 | Figma 交互原型（可分享链接） |
| 付费展示 | **首版验证与首次使用不强调付费**；先体验，碰到额度墙再温和提示 |

---

## 3. 范围

### 3.1 MVP 做

- 注册/登录（手机号或 Sign in with Apple）
- 创建家庭 / 邀请码加入；每用户 MVP 限属于 **1 个家庭**
- 药箱位置（空间）增删改查
- 药品录入：扫条码 + 拍照 OCR；必填位置、效期；选填开封管理
- **连续录入**：保存后回到扫码，位置默认沿用上一次
- 首页：家庭名、搜索、三色效期看板、按位置列表
- 找药：文字搜索 + 症状快捷标签；结果大字号展示药名 / 位置 / 效期；过期药标红沉底
- 本地缓存 + 家庭云同步（账号体系下的同步）
- 「我的」：成员列表、邀请码/分享、退出家庭；升级入口仅轻量展示

### 3.2 MVP 不做

- 管理员 / 仅查看权限
- 远程帮父母专用极简界面
- 语音 ASR
- 服药提醒
- Android / 微信小程序
- 开屏或主流程中的付费墙强推
- 购药跳转 / 用药剂量建议（合规：仅检索自家库存）

---

## 4. 信息架构

**底部 Tab：**
1. **首页** — 看板 + 位置 + 顶部搜索  
2. **录入（+）** — 主操作  
3. **我的** — 家庭、账号、轻量升级入口  

家庭不是独立 Tab：在「我的」管理；首页顶栏显示当前家庭名（如「张家药箱」）。

**核心对象：**
- 用户 ∈ 1 个家庭（MVP）
- 家庭 = 多名成员（全员对等）+ 多个位置 + 多个药品
- 药品归属位置，变更实时同步至家庭成员

---

## 5. 关键用户流程

### 5.1 创建 / 加入家庭

1. 登录成功  
2. 若无家庭 → 空状态二选一：「创建家庭药箱」/「输入邀请码加入」  
3. 创建：填写家庭名 → 进入首页  
4. 加入：输入 6 位码 → 确认家庭名 → 进入同一首页  
5. 「我的 → 家庭」：成员列表、复制邀请码/分享链接、退出家庭  

### 5.2 极速录入（共享写入）

1. 点底部「+」→ 扫码或拍照 OCR  
2. 自动填充药名、功效标签  
3. 必填：存放位置（可新建）、有效期；选填：开封状态  
4. 保存 → 同步到家庭药箱  
5. 默认「保存并继续录入」，位置沿用上一次  

### 5.3 紧急找药（共享读取）

1. 首页搜索框输入症状/药名，或点症状标签（腹泻、感冒、发烧等）  
2. 仅在本家庭已录入药品中匹配功效标签 / 说明书关键词  
3. 结果卡大字号：**药名 · 位置 · 效期状态**  
4. 过期药可展示但标红并沉底  
5. 固定免责声明：「仅展示家中已有药品，不构成用药建议」

## 6. Figma 原型规格

### 6.1 画板与页面（主故事 9 帧，无付费墙）

| # | 页面 | 说明 |
|---|---|---|
| 1 | 登录/注册 | 极简 |
| 2 | 家庭空状态 | 创建 / 加入 两个主按钮 |
| 3 | 创建家庭 | 家庭名 |
| 4 | 加入家庭 | 邀请码 + 家庭名确认 |
| 5 | 首页 | 家庭名、搜索、三色看板、位置列表、底 Tab；预填 4–5 种示例药 |
| 6 | 录入-扫码 | 大扫码区 |
| 7 | 录入-确认表单 | 含「保存并继续录入」 |
| 8 | 找药结果 | 大字号位置强调 |
| 9 | 我的-家庭 | 成员、邀请、退出；升级为小字链接（不串进主 Prototype） |

付费墙可作附录帧，**不进入默认 Prototype 主路径**。

### 6.2 主 Prototype 故事线（给用户点）

登录 → 创建「张家药箱」→ 首页 →「+」录入一盒 → 回首页 → 搜「拉肚子」→ 结果页 →「我的」看邀请码  

### 6.3 制作规范

- 尺寸：iPhone 15（390×844），Auto Layout  
- 组件化：底 Tab、药品卡、效期标签、主按钮  
- 分享：Anyone with the link can view  
- 产品名暂定：**家药箱**（可改）  
- 首页卖点文案：「一人录入，全家能找」  

### 6.4 验证问卷（不问价）

- 会不会下载使用？  
- 会不会邀请家人一起用？  
- 哪里卡住 / 缺什么？  

付费意愿放到第二轮验证。

## 7. 付费策略（产品层，非首版强调）

**原则：** 先体验，后转化；首次使用与主流程零付费打扰。

| 阶段 | 行为 |
|---|---|
| 首次使用 | 不展示付费 |
| 免费额度内 | 约 15–20 种药、约 20 次 AI 识别，无打扰 |
| 触达上限 | 可关闭的温和提示；不阻止浏览已有药品 |
| 「我的」 | 轻量「解锁完整版」入口 |

**免费必须包含：** 创建家庭、邀请家人、全员共用药箱（差异化体验不能锁在付费墙后）。  
**Pro 能力（实现阶段再落地，验证阶段不推）：** 无限药品数量、无限 AI 识别次数等用量型能力——而不是「能不能邀请家人」。  
**定价参考（调研）：** 国内买断约 ¥12–28；验证阶段不对外报价格。

---

## 8. 合规与安全（MVP 约束）

- 找药 = **检索用户自家库存**，匹配依据为说明书功能主治原文/标签，不提供选药、剂量、疗程建议  
- 不做购药跳转  
- 国内展示药品信息存在「互联网药品信息服务」备案要求；MVP 策略：数据以家庭私有库存为主、说明书摘要最小化展示，并保留完整说明书入口与免责声明；有收入后评估企业主体备案  
- 健康数据：账号同步需加密传输；支持退出家庭后不再可见该家庭数据  

---

## 9. 技术方向（规格级，非实现细节）

- 客户端：原生 iOS（SwiftUI 优先）或跨端方案在实现计划中再定  
- 后端：账号 + 家庭 + 药品/位置的 CRUD 与实时/近实时同步  
- 外部能力：药品条码 API、OCR（效期/药名）；语音 ASR 不做  
- 离线：已同步数据可本地读；写入在恢复网络后同步  

实现计划阶段再拆任务与选型。

## 11. 原型反馈修订

### 11.1 第一轮（2026-07-12 下午）

| # | 决策 |
|---|---|
| 1 | 药品展示必须含**具体有效期日期**，状态标签仅作辅助 |
| 2 | 药品有**数量**字段；同名药合并，效期取**最早过期日** |
| 3 | **录入入口弱化**：去掉底栏中央「＋」 |
| 4 | **登录 / 建家庭延后**：打开直接进本机药箱 |

### 11.2 第二轮（2026-07-12 傍晚）

| # | 决策 |
|---|---|
| 1 | **家庭成员管理**：家庭创建后进入成员页；支持查看成员、邀请码/分享、移除成员、家庭改名、退出共享 |
| 2 | **货架式库存**：首页按位置分区展示充足示例药品（约 14 种、3 个位置），避免「空货架」观感 |
| 3 | **视觉升级**：衬线标题 + 无衬线正文、雾面卡片、氛围底图、浮动底栏、入场动效；色系为森绿 + 暖石色 |

信息架构：底 Tab 仍为 **首页 | 我的**；成员管理在「我的 → 家庭与成员管理」。

### 11.5 首页核心信息与健康事件（2026-07-12）

**首页药品卡片必须露出：**
1. **真实包装照片**（主视觉：方便长辈对照实物药盒）
2. 药品名称
3. **适应症关键词**（如 感冒 · 发热）
4. **临期时间文案**（如「临期 · 还剩 16 天」/「已过期 63 天」/「有效至 27-08-15」）
5. 库存数量+单位（次要）

录入时拍摄包装正面；真机以用户自拍包装为准。

**健康事件管理：**（详见 `2026-07-12-event-course-reminders-design.md`）

- 定位：A 疗程依从 + B 找药 + C 家庭协同，**B 优先**；事件是疗程本，不是问诊
- 双轨：药品 Tab 找药；事件 Tab 管计划/待服/流水；首页仅克制展示「今日待服」条
- 先建轻量事件，再补用药计划（多药 × 钟点 × 天数）；提醒挂在计划上
- 取用：从事件出发必关联；有进行中疗程时默认带入；保健可快速取用
- 复评提醒（满 N 天）与服药提醒分开；不做剂量建议

示例：孩子感冒 7 天 = 美林 + 小儿感冒多钟点计划 → 推送确认 → 扣库存 + 流水。

### 11.6 包装照片（2026-07-12）

为降低识字负担，首页与找药结果优先展示**真实包装照片**（录入时拍摄药盒正面），再配药名与适应症，便于长辈对照家中实物药盒取药。原型示例药使用药盒产品照；真机以用户自拍包装为准。
