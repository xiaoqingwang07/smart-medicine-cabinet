## 1. 定位

**一句话：** 先帮你在家里找到药；该吃药时提醒你；每季度给你一张能发朋友圈的家庭药箱体检卡。

| 优先级 | 能力 |
|--------|------|
| P0 | 找药（包装照对照） |
| P0 | 用药提醒（今日待服、钟点、确认服用） |
| P1 | 轻事件标签（谁 / 因何事，可选） |
| P1 | 家庭共享 |
| P2 | 季度囤药账单 + 安全报告（免费可分享） |

**不做：** 诊断、剂量建议、购药导流、替代就医。

---

## 2. 信息架构

**底栏：药品 | 我的**（不再设独立「事件」Tab）

### 2.1 药品首页（双区）

1. **上区 · 今日提醒**  
   - 有待服：列表 + 确认 / 稍后 / 跳过  
   - 无待服：仍保留精简区（「今日暂无待服」+ 管理计划 / ＋提醒），避免入口消失  
   - 入口：管理计划、新建提醒  
2. **下区 · 找药**  
   - 搜索、症状标签、效期看板、包装照药卡  

### 2.2 我的

- 添加药品、家庭成员、登录  
- **家庭药箱季报**（隐蔽但必有）  
- 通知权限等  

---

## 3. 提醒（重）与事件（轻）

### 3.1 主对象：用药计划

选药、每次用量、钟点（可多选）、连续天数、提醒开关。  
由计划生成「今日待服」；确认服用 → 扣库存 + 可选写入流水。

### 3.2 轻事件标签（可选）

建计划时可填：给谁、因何事。可空。  
仅作筛选/展示标签，**不作为主工作台**。

### 3.3 管理计划页

进行中计划列表；可暂停/结束；结束后不再生成待服。

---

## 4. 季度囤药账单 + 安全报告

- **周期：** 每季度  
- **权限：** 完全免费，可生成分享海报（传播引擎）  
- **入口：** 我的 → 家庭药箱季报；效期压力大时可轻提示，不抢找药区  

### 4.1 报告内容

| 模块 | 示例 |
|------|------|
| 社交货币 | 囤了 24 种药，击败约 89% 家庭（示意分位） |
| 风险 | 已过期 N（失效/处置风险提示） |
| 临期 | 即将过期 N |
| 浪费 | 预计浪费约 ¥XXX（品类均价估算） |
| 盲区 | 类目缺口（如缺儿童退烧 / 外伤） |
| 实用下一步 | 一键查看过期清单、临期清单 |

语气：**风险提示 + 实用指南**；固定免责：不构成医疗建议；分位与金额为估算示意。

### 4.2 分享

一键生成竖版海报，适配小红书 / 朋友圈。原型内展示可截图卡片即可。

---

## 5. 原型验收

1. 底栏仅 药品 | 我的  
2. 首页有待服时置顶展示，可确认服用并扣库存  
3. 可新建提醒计划（事件标签可选）  
4. 管理计划可结束计划  
5. 我的可打开季报，见囤药数/击败%/过期/临期/浪费/盲区，可「生成分享卡」  
6. 找药网格与包装照仍在首页下区
