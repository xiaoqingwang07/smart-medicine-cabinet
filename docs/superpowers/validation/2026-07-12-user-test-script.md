# 家药箱用户测试脚本

**日期：** 2026-07-12  
**原型形式：** HTML 可点击原型（替代 Figma，内容对齐规格主故事）  
**原型路径：** `prototype/index.html`  
**本地打开：** 见下方「如何打开」  
**目标人数：** ≥5（有娃家庭或需照顾老人的家庭）  
**单场时长：** 10–15 分钟  

## 如何打开

在项目目录执行：

```bash
cd "/Users/test/cursor/智能药箱"
python3 -m http.server 8765
```

浏览器打开：http://localhost:8765/prototype/  
（手机与电脑同一局域网时，可用电脑 IP 替换 localhost，便于真机点）

或直接用浏览器打开文件：`prototype/index.html`

## 开场（1 分钟）

「我在做一个家庭药箱小工具的原型，想请你帮我点一点、说说真实感觉。没有对错，不是考试。这不是成品 App。」

## 任务（让用户自己点，少提示）

1. 打开后直接看首页：能否看懂某药的**具体有效期**和**数量**，并试着加减数量  
2. 用首页右上角「添加药品」走一遍扫码→确认（含数量）→保存  
3. 用「拉肚子」或点「腹泻」找药，看结果里的日期与位置是否够清楚  
4. （可选，勿强迫）到「我的」里找登录 / 家庭共享入口，看是否感觉「需要时才用」  

观察：哪里停顿、录入入口是否难找、是否理解「先本机用、家庭共享可选」。

## 访谈问题（问完任务再问；不问价格）

1. 如果正式上线，你会不会下载使用？为什么？  
2. 你会不会邀请家人一起用？卡点是什么？  
3. 刚才哪里让你觉得烦或看不懂？  
4. 还缺什么功能你才会真正坚持用？
