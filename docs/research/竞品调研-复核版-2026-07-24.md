# 家药箱 · 竞品调研（复核版）

> 复核日期：2026-07-24
> 复核对象：`产品调研报告.md` 第三章「竞品分析」
> 复核动因：原报告将竞品范围框定为「2025 下半年后上架的独立开发作品」，遗漏了 2021–2023 年就已上架的存量玩家，导致「家庭共享是最大空档」这一核心差异化假设可能不成立。
> 数据口径：中国区 / 美区 App Store 官方页面（评分数、定价、版本历史、开发者主体均为页面直读），核验时间 2026-07-24。

---

## 一、结论先行

1. **「家庭共享几乎没人做好」这个判断，错了一半。** i药管家早在 2025 年 5 月（v2.2.7）就上线了「成员视图 + 成员权限设置 + 用药提醒分享」，App 描述里明确写着「共享药箱」和「关联账号查看家人服药记录」。它不是即将上线，是跑了一年多的功能。

2. **但更重要的是：整个品类的天花板被评分数暴露了。** 国内最强的一款三年只有 89 个评分，其余在 3–15 个之间。这不是红海，是**一个小池塘里挤满了船**。你可以打赢所有人，然后发现奖品只有几千块。

3. **原报告低估了拥挤程度。** 除了它列的 5 款，我在竞品的「你可能还喜欢」里又直接数出 15+ 款同类 App，App ID 集中在 675x–676x 区间，说明**全部是最近几个月新上架的**。其中「吃药管家：拍照AI识别药盒&处方单&智能吃药提醒&库存管理」的功能描述，几乎等于你 PRD 的逐条复述。

4. **真正的技术痛点被用户点名了。** 小药盒的差评原话：「只能支持扫码识别药品，但是有些药又识别不出」「不能扫描识别药物，全靠手输入」。这坐实了上一轮 review 里说的 OCR/条码尖刺不是假设风险，是**已经在竞品身上翻过车的真实风险**。

5. **海外存在一个跟你几乎完全同构、且已跑在前面的产品：mojApteczka（波兰）。** 它把你规划的东西全做了，还多做了药物相互作用和儿科分级。

6. **「订阅制在这个品类不成立」这个结论要推翻。** 海外同类普遍在收订阅，且 Medisafe 从 2026 年 1 月起把免费档砍到 2 种药——头部在收紧而不是放松，说明付费意愿是被验证过的。

## 三、用户真实声音（这部分最有价值）

我把能读到的评论原话按主题归类：

**① 识别率是第一杀手**
- 「只能支持扫码识别药品，但是有些药又识别不出」（小药盒，2025-05-27）
- 「不能扫描识别药物，全靠手输入，超过8个还要收费，要你何用啊」（小药盒，2026-01-02）

**② 免费额度设太小 = 直接一星**
- 同上那条差评的后半句。小药盒免费档只给 8 种药，用户的反应是愤怒而不是升级。
  → 你规划的 15–20 种是合理下限，**不能再低**。

**③ 用户会自发想把它变成「全屋物品管理」**
- 「昨天把家里的药都记录好后突然想到其他日用品也可以加进去，只要分类做得好，很多东西都可以标记物品放置区域，这样再也不担心重复购买和物品过期……如果能加个加减库存的功能就更好了」（小药盒，2025-10-29）
  → 两个信号：一是**位置标记（放置区域）确实是用户主动想要的**，印证你的位置维度设计；二是低频问题的天然解法是扩品类，但那会把你推进「过期啦/收起来」的战场。

**④ 多药箱/多地点是真需求**
- 「每天两地奔波，需要在两地都备药，APP 里只能设置一个药箱是不够的」（药准时，2026-03-31）

**⑤ 计划可编辑性**
- 「服药计划不能改，只能删了重建……医生改成隔一天服用，这就需要服药计划能够修改」（药准时，2026-05-22）
  → 如果你做提醒，计划编辑从 v1 就要做对。

## 五、对「家药箱」四个亮点的重新评估

上一轮 review 我给了四个「真有价值」的点。核验完之后要修正两个：

| 亮点 | 上轮判断 | **复核后** |
|---|---|---|
| **包装照片对照** | 「整个项目最好的洞察」 | ⬇️ **降级。** Pillo「attach package photos」、Pharma Pal「Add photos for easy identification」都已做。仍是对的设计，但**不是壁垒**。我上次的说法要收回一半。 |
| **位置（哪个抽屉）** | 竞品做得浅 | ➡️ **国内成立，海外不成立。** 国内只有分组/标签；海外 PillKit、Pills.Kit 都已按物理位置分箱。且有用户评论主动要这个功能。 |
| **季度囤药报告 + 分享海报** | 唯一有传播潜力的设计 | ✅ **维持，仍是空档。** i药管家有「用药周报告」但那是依从性向；「囤了24种药击败89%家庭」这种社交货币形态，国内外都没人做。 |

## 七、建议的动作变更

1. **把 P0 从「家庭共享」换成「中文语义找药 + 效期识别率」。** 前者已被占领且没带来任何量，后者是唯一没被吃掉的空档，且是竞品公认的翻车点。家庭共享降为 P1——做，但别当卖点。

2. **技术尖刺仍是开发前的第一优先级**，且现在有了外部证据支撑：竞品因为识别不出药而吃差评。目标定 30 盒真实国产药盒，单盒效期识别率 ≥85%。

3. **国内合规抄小药盒的作业**：类别选「健康健美」、纯本地存储、隐私声明「未收集数据」、不建药品信息库。这套组合已被验证可以上架且规避了「互联网药品信息服务」的定性。

4. **定价**：首发 ¥12 封顶（小药盒 ¥8 是当前地板），免费额度 ≥20 种药、AI 识别送 20 次。

5. **海外别只盯美区。** mojApteczka 证明欧洲这个品类有付费市场且能收月订阅；MyCabinet 证明美区的家庭共享方案存在明显短板（没有识别录入、没有效期）——**这恰好是你的强项所在，是比国内更值得打的缺口**。

6. **重新校准预期。** 国内最好的玩家三年 89 个评分。如果目标是「爆款」，这个赛道给不了；如果目标是「一个做得比所有人都好的小工具 + 出海」，路是通的。
